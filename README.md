## About
Nexus Union Roleplay ist ein modulares Roleplay-Framework, das seinen Schwerpunkt auf Erweiterbarkeit, Performance und eine immersive Benutzeroberfläche legt. Entwickelt mit C# und modernen Webtechnologien, bietet es Kernsysteme (Berufe, Inventar, Berechtigungen) sowie einfache Schnittstellen für eigene Inhalte.
