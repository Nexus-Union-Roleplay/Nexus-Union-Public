## About
Nexus Union Roleplay is a modular roleplay framework focused on extensibility, performance, and immersive UI. Built with C# and modern web tech, it provides core systems (jobs, inventory, permissions) and easy hooks for custom content.

---

## Features
- **Modular architecture** for easy feature toggling and plugin development  
- **Inventory system** with item stacking and persistence  
- **Job and economy framework** with configurable pay and progression  
- **Secure permissions** and role management  
- **Responsive UI** components (HTML / SCSS) for in‑game overlays  
- **Automated build workflows** for .NET and SLSA integration
